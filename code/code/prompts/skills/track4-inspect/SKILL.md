1. embed_head_inspect对每张输入实时计算视觉向量，轨道监督头与桥梁presence/案例投票产生初判。
2. 按视觉风险、训练支持度、健康抽检和病害结果分层抽检选择复核队列，最多6条，模型加载计入120秒预算。
3. teacher_review调用匹配底座与clean_full LoRA的27B独立检查原图；不向教师提供学生答案、文件名、桥名或金标。
4. 验收合法闭集JSON。桥梁初判presence在阈值及其上方0.1内、教师明确完好且有可见依据时允许纠正；轨道病害改完好仍阻断。任何视角都不能强制完好。
5. 非法、不确定、超时或未复核行保留初判。描述为训练代表句；桥梁未知标度保留案例来源，不宣称国标自动定级。
6. 七字段合同验收后保存结果、真实全流程计时与审计，工具摘要写入本次SimpleMemory。

模型预测和参考包均不构成人工真值。在线与现场执行相同配置，只允许合法输入身份变化。
